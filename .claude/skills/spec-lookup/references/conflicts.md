user decides it.

**Precedence** (tech:347-394): safety › prd › techspec › database › plan ›
appflow › design. If a conflict doesn't materially affect implementation, take
the least complex compatible reading.

format (Document A / Document B / Resolution / Reason / Implementation Impact).
